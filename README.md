MarkCraft Everest 1.0 Official

The first official release of the system information utility by MarkCraft Corporation!

What's inside?
*   **System Info:** Detailed information about your OS, CPU, RAM, and Video Card.
*   **Safe Sensors:** Read CPU temperatures and frequencies safely (no dangerous drivers, no BSOD!).
*   **Licensing System:** Protection with keys tied to your PC. Available editions: Home, Professional, Max, and Ultra.
*   **Account System:** License binding to your MarkCraft account.
*   **Design:** MarkCraft brand style (dark background, yellow accents).

How to install?
1. Download the `MarkCraftEverest_Setup_1.0.exe` installer below.
2. Run it and follow the instructions (accept the license agreement).
3. The program will install into your user folder and create a desktop shortcut.

System Requirements
*   OS: Windows 10, 11 (recommended).
*   Internet: required for license activation.
